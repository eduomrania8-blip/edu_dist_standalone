# منظومة التوزيع الذكي - Standalone

هذا المشروع هو نظام مستقل تماماً لإدارة وتوزيع الموجهين في إدارة العمرانية التعليمية.

## التقنيات المستخدمة
- **Next.js 15+** (App Router)
- **Supabase** (Database)
- **Tailwind CSS** (Styling & Glassmorphism)
- **Framer Motion** (Animations)
- **html2pdf.js** (Advanced Printing)

## كيفية البدء

1. **إعداد قاعدة البيانات:**
   - اذهب إلى مشروعك في [Supabase](https://supabase.com).
   - افتح الـ **SQL Editor**.
   - الصق محتوى الملف `supabase/migrations/001_initial_schema.sql` واضغط على **Run**.

2. **تثبيت الاعتمادات:**
   ```bash
   npm install
   ```

3. **تشغيل المشروع:**
   ```bash
   npm run dev
   ```

4. **المزامنة:**
   - بعد تشغيل التطبيق، اضغط على "مزامنة من Google Sheets" لجلب بيانات المدارس والموجهين.
   - ثم اضغط على "تشغيل التوزيع الذكي" لحساب النتائج.

## مميزات النظام
- **توزيع ذكي:** يراعي رغبات الموجهين (من الرغبة 1 إلى 4).
- **عدالة التوزيع:** يوزع المتبقي بشكل منصف على المدارس المتاحة.
- **طباعة متقدمة:** استخراج نشرات توزيع رسمية بصيغة PDF.
- **مزامنة فورية:** جلب البيانات من Google Sheets بضغطة زر.
